# Annotate Markdown

Review a Markdown file in a separate window and send the comments to Pi.

## Use

Run:

```text
/annotate path/to/file.md
```

Select source text to add a comment, or add a whole-document comment. Choose **Send ⌘↵** to send the comments or **Insert ⌘⇧↵** to place them in the editor.

## Shortcuts

| Action | Shortcut |
| --- | --- |
| Add a document comment | `D` |
| Edit the active comment | `E` or `Enter` |
| Remove the active comment | `X` |
| Previous / next comment | `K` / `J` |
| Toggle line wrapping | `W` |
| Save a comment | `⌘ Enter` |
| Send comments | `⌘ Enter` |
| Insert comments | `⌘ Shift Enter` |
| Undo a removed comment | `⌘ Z` |
| Clear all comments | `⌘ Backspace` |
| Cancel the current action | `Esc` |
