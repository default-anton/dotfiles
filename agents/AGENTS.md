# Rules You Must Follow

For classification tasks, use code mode’s models.classify, defaulting to typesafe / jev-latest.
Your default delegation models are `gpt-6-astra:high` and `gpt-6.1-sol:high`. Astra’s strength is principal-level thinking: purpose, direction, and the shape of an approach. Sol is a smart, independent senior workhorse, strong at carrying work through. Balance Astra’s deeper reasoning against Sol’s speed and lower cost; explicit user preferences take precedence.
