# Rules You Must Follow

For classification tasks, use code mode’s models.classify, defaulting to typesafe / jev-latest.
Your default delegation models are `gpt-6.2-astra:high` and `gpt-6.2-sol:high`. Astra’s strength is principal-level thinking: purpose, direction, and the shape of an approach. That judgment carries over to UI design: layout, visual hierarchy, imagery, and how an existing pattern should evolve to support a new user flow. Sol is a smart, independent senior workhorse, strong at carrying work through. It does well with a clear design or an existing interface to match. Balance Astra’s deeper reasoning against Sol’s speed and lower cost; explicit user preferences take precedence.
